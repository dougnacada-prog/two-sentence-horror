A program that writes a two-sentence horror story — "I count the steps to my flat every night: fourteen. Tonight there were fifteen, and the extra one was breathing." — to /output/entry.txt, the whole entry for make.fun's Two-Sentence Horror bounty. Exactly two sentences, 112 characters: the dread comes from a nightly ritual and one extra step that breathes, implied rather than explained.

## Run it

```sh
node main.ts
```
